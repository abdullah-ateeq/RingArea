# RingArea

RingArea is an Android application built with Jetpack Compose that helps you calculate the area and other properties of a ring (annulus) accurately and efficiently.

## Features
- **Calculator**: Quickly calculate the area of a ring using various inputs (e.g., inner radius, outer radius, thickness).
- **Dynamic Diagram**: Visualize the ring dimensions with a responsive, interactive diagram.
- **History**: Automatically keeps track of your past calculations for easy reference.
- **Settings**: Customize calculation units, app theme, and precision according to your preferences.
- **Mathematical Formulars**: View step-by-step mathematical formulas generated for your calculations.
- **Modern UI/UX**: Designed using Jetpack Compose and Material Design 3 guidelines.

## Tech Stack
- **Language**: Kotlin
- **UI Toolkit**: Jetpack Compose
- **Design System**: Material Design 3
- **Architecture**: MVVM (Model-View-ViewModel)
- **Local Storage**: DataStore Preferences
- **Serialization**: Gson
- **Navigation**: Jetpack Compose Navigation

## Requirements
- Android 7.0 (API level 24) or higher

## Getting Started
1. Clone this repository:
   ```bash
   git clone https://github.com/abdullah-ateeq/RingArea.git
   ```
2. Open the project in Android Studio.
3. Build and run the app on an emulator or a physical device.
